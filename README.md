# До свидания · 直到下次再见

等待达妮娅（《鸣潮》共鸣者 Denia / ダーニャ / 데니아）的非官方粉丝纪念馆。
v3（2026-10-27）在旧站基础上整体重制：**双形态主题、泡泡粒子层、归档画廊、二创日报、桌宠互动**，
旧站素材与灵魂元素（等待计数、蛋糕仪式、相机相册装帧、迷你桌宠、до свидания 的语气）全部保留。

## 运行

```bash
node server/server.js     # 或 npm start；PORT 可改，默认 4173
```

**也可以不用服务器**：本站为纯静态、零构建、零 CDN 依赖，数据内联在 `assets/js/data*.js`，
直接用浏览器打开 `index.html`（file://）即可运行；画廊图片按原站 URL 远程加载，原站不可达时优雅降级。

## 设计与礼仪底线

- **素材零丢失**：原站图片全部沿用原 URL（归档图与相机装帧）或本地镜像（传承主视觉），不替换、不删除。
- **署名零丢失**：署名同人带作者与原作链接；归档图署名待补处以 `data-slot="credit-*"` 明确占位。
- **剧透默认折叠**：3.2–3.3 主线内容需点「我已通关，展开」；首页与分享卡不含剧透。
- **官方 / 原创区分**：官方台词带引号与出处标签；站点氛围文案标「站点」。
- 非官方粉丝站，与库洛游戏无隶属关系；《鸣潮》相关版权归原权利人所有；二创版权归各自作者，不商用。

详见 `DELIVERY.md`（诊断 / 概念 / 素材映射表 / 待补清单 / 迭代方向）。
